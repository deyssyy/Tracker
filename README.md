# Tracker ⏱️

Приложение для создания, планирования и отслеживания регулярных привычек и нерегулярных событий с гибкой фильтрацией.

---

### ✨ Фичи и возможности
- 📅 **Управление привычками:** Создание повторяющихся задач по дням недели или разовых событий.
- 🎨 **Кастомизация:** Выбор уникального цвета и эмодзи для каждого трекера при создании.
- 🔍 **Фильтрация и поиск:** Поиск по названию, фильтрация по категориям и выбранной дате в календаре.
- 📊 **Статистика:** Учет прогресса выполнения, подсчет идеальных дней и общего количества завершенных задач.

---

### 🛠️ Стек технологий и Архитектура

- **Архитектура:** `MVVM` / `MVP` (строгое разделение ответственности слоев и подготовка к тестированию).
- **UI:** `Swift` • `UIKit` • `UICollectionView` • `Auto Layout` кодом (без Storyboards).
- **Данные:** `Core Data` (многотабличная база данных, сохранение состояния между перезапусками).
- **Паттерны:** `CoreDataResultController` для плавного обновления таблиц, фабрики и делегаты.
